**NestBudget** — a calm household budget site for an Indonesian family, in Rupiah (IDR). It tracks income and expenses across seven categories with monthly budgets, a donut and weekly-spending view, savings goals with progress, a Bills & recurring panel (rent, utilities, subscriptions — Rp 5.375.000 due every month in the demo data), a month-over-month insight comparing each category with the previous month, and a one-page printable summary. It works 100% offline: plain static files, in-memory state, no build step, nothing loaded over the network. `main.ts` hands the site in — it copies `app/` and `screenshots/` to the output directory and writes the dossier with the vendored make.fun library.

## Run it

```sh
node main.ts
```

Open `app/index.html` in a browser to use the site itself.
